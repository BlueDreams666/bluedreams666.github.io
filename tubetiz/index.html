Help for Tubetiz: NoneOfYa! Vault

Questions or problems? Email barmaor.co@gmail.com. We usually reply within a couple of days.

I forgot my password

There is no way to reset or recover it. That's what keeps your vault safe: nobody, including us, can open it without the password. If you made a backup, you can restore it with the password the vault had when the backup was made.

Moving to a new iPhone

The vault isn't included in iCloud or computer backups. In the app, open Settings › Back Up Vault, save the file somewhere safe (Files, a drive or your Mac), then use Settings › Restore from Backup on the new iPhone.

I deleted something by mistake

Open Albums › Recently Deleted. Items stay there for 30 days.

How do I hide the app?

Settings › Home Screen Icon lets you pick a plain icon. Settings › Use Any Name and Icon explains how to use a Shortcut with any name and picture.

What is the decoy vault?

A second password that opens a separate vault. Set it up in Settings › Decoy Vault.
